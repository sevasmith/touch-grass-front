# Contract: Consumed Backend API

**Source of truth**: `docs/backend-readme.md`. This file lists the subset the frontend consumes
and how each outcome maps to an `AuthErrorCode` ([data-model.md §4](../data-model.md#4-error-model--srcfeaturesauthmodelauth-errorts)).
All calls are made **server-side** by the BFF (`backendFetch` / `authedFetch`), except
`GET /auth/google`, which is a browser navigation.

Common to every call: an 8 s timeout, `X-Forwarded-For` forwarded, the success body parsed with the
listed Zod schema, and non-2xx bodies parsed with `ApiErrorSchema`. A network failure or abort maps
to `NETWORK_ERROR`, an unlisted `5xx` maps to `SERVER_ERROR`, and an unlisted `429` maps to
`RATE_LIMITED` (the backend throttles most routes at 20 requests/minute per IP).

| #   | Method & path                    | Tier (backend)  | Caller                      | Request body                | Success             | Refresh-retry on 401?                           |
| --- | -------------------------------- | --------------- | --------------------------- | --------------------------- | ------------------- | ----------------------------------------------- |
| 1   | `POST /auth/signup`              | Public          | `register` action           | `{ email, password }`       | `201` `TokenPair`   | no                                              |
| 2   | `POST /auth/login`               | Public          | `login` action              | `{ email, password }`       | `200` `TokenPair`   | no                                              |
| 3   | `POST /auth/logout`              | Public          | `logout` action             | `{ refreshToken }`          | `204`               | no (result ignored)                             |
| 4   | `POST /auth/refresh`             | Public          | refresh coordinator         | `{ refreshToken }`          | `200` `TokenPair`   | n/a                                             |
| 5   | `POST /auth/forgot-password`     | Public          | `forgotPassword` action     | `{ email }`                 | `200` `{ message }` | no                                              |
| 6   | `POST /auth/reset-password`      | Public          | `resetPassword` action      | `{ token, password }`       | `204`               | no                                              |
| 7   | `POST /auth/verify-email`        | AllowUnverified | `verifyEmail` action        | `{ code }` (6-digit string) | `204`               | **only** for non-code 401s                      |
| 8   | `POST /auth/resend-verification` | AllowUnverified | `resendVerification` action | none                        | `204`               | yes                                             |
| 9   | `GET /auth/google`               | Public          | **browser `<a href>`**      | none                        | `302` → Google      | n/a                                             |
| 10  | `POST /auth/oauth/exchange`      | Public          | `exchangeOAuthToken` action | `{ token }`                 | `200` `TokenPair`   | no                                              |
| 11  | `GET /auth/me`                   | AllowUnverified | proxy, actions, RSC         | none                        | `200` `CurrentUser` | yes (proxy & actions only; RSC never refreshes) |

the proxy treat it as `transient` and keep the session (FR-013).

The final copy may be adjusted during implementation. The **distinctions** in this table may not:
each row keeps its own code (constitution: preserve backend distinctions).
